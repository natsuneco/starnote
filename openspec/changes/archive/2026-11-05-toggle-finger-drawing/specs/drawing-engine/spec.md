# Spec Delta

## ADDED Requirements

### Requirement: 指タッチ操作の描画/スクロール切り替え
システムは、エディタ画面において指（touch）による操作を「手書き描画」として扱うか「紙面のパン・スクロール」として扱うかを切り替える設定を提供し、設定に応じたポインターイベント制御を行わなければならない (SHALL)。

#### Scenario: 指スクロールモード（指描画OFF）での指操作
- **WHEN** 指で描画設定がOFFの状態でユーザーが指（touch）で紙面をドラッグしたとき
- **THEN** インク描画は開始されず、ブラウザ標準の縦スクロール・パン移動が行われる

#### Scenario: 指スクロールモード（指描画OFF）でのペン描画
- **WHEN** 指で描画設定がOFFの状態でスタイラスペン（pen）で紙面をなぞったとき
- **THEN** 手のひらや指の画面接触による誤描画を完全に防止しながら、スタイラスによるストローク描画が正常に行われる

#### Scenario: 指描画モード（指描画ON）での指操作
- **WHEN** 指で描画設定がONの状態でユーザーが指（touch）で紙面をなぞったとき
- **THEN** 指のタッチ位置に追従して手書きインクストロークが描画される

#### Scenario: 指操作設定の永続化
- **WHEN** ユーザーが指描画のON/OFFを切り替えたとき
- **THEN** その設定がローカルストレージに保存され、別ノートの閲覧時やアプリ再起動後も設定状態が維持される
