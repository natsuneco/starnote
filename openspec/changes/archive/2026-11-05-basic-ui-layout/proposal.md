# Proposal

## Why

StarNoteにおける基本的なノート体験を提供するため、ノート一覧（ホーム画面）、ノート新規作成ダイアログ、および上部ツールバーと縦スクロール対応の紙面を備えたノート編集画面のUIを構築します。共通コンポーネントを統一し、ライトモード基調で将来のダークモード対応が容易なデザインシステムを確立します。

## What Changes

- アイコンライブラリ `lucide-react` の導入
- 統一された共通UIコンポーネント（Button, IconButton, Card, Modal, Input）の実装
- ノート一覧（ホーム）画面の実装（新規作成カード、ノート一覧グリッド、削除機能）
- ノート新規作成モーダル（タイトル入力）の実装
- ノート編集画面の実装（ホームへ戻るナビゲーション、タイトルインライン編集、上部ツールバー、ペン/マーカー/消しゴム/なげなわの切り替え、カラーパレット）
- 編集画面における縦スクロール可能なノート紙面ビューポートの構築

## Capabilities

### New Capabilities
- `notebook-ui`: ホーム画面（一覧表示・作成・削除）とノート編集画面（ツールバー操作・縦スクロール紙面表示）を相互に行き来できるノートUIナビゲーションおよびレイアウト。

## Impact

- `lucide-react` パッケージの追加
- `src/components/ui/` 配下に汎用UIコンポーネント群を新設
- `src/components/home/` および `src/components/editor/` 配下に画面固有コンポーネントを追加
- `App.tsx` またはルータによるホーム画面と編集画面の画面状態管理の導入
