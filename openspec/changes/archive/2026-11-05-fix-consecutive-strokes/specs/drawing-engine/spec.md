# Spec Delta

## ADDED Requirements

### Requirement: 連続ストローク入力の確実な受け付け
システムは、ストローク終了直後に次のストロークが開始された場合でも、入力間隔に関係なくすべてのストロークを描画・確定しなければならない (SHALL)。描画面上ではブラウザ標準のダブルタップ判定などのジェスチャがストローク入力を妨げてはならない (MUST NOT)。

#### Scenario: 素早い連続ストローク
- **WHEN** ユーザーがペンまたは指で1本目のストロークを描き終え、間を空けずに2本目のストロークを描いたとき
- **THEN** 2本目のストロークも1本目と同様に描画中から表示され、ペンを離すと確定される

#### Scenario: 短い点の連打
- **WHEN** ユーザーが句読点や濁点のように短いストロークを素早く連続で描いたとき
- **THEN** すべての点・短い線が欠落せずに確定される

#### Scenario: ブラウザによる入力中断
- **WHEN** 描画中のストロークがブラウザ側の理由で中断（pointercancel）されたとき
- **THEN** それまでに描かれた部分はストロークとして保持され、次のストローク入力は正常に受け付けられる

#### Scenario: 連続描画後の取り消し
- **WHEN** 素早く連続で描いた複数のストロークに対して「元に戻す」を実行したとき
- **THEN** ストロークが1本ずつ、描いた順と逆順に取り消される
