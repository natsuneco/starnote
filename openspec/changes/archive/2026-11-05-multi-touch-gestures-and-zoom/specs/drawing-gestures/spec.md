# Spec Delta

## ADDED Requirements

### Requirement: 2本指タップによる取り消し (Undo)
システムは、キャンバス面上で2本の指による素早いタップ操作（規定時間以内かつ指の移動量が微小な接触）を検知したとき、直前のストローク描画または消去操作を1ステップ元に戻さなければならない (SHALL)。このジェスチャーによって意図しないインク描画が発生してはならない (MUST NOT)。

#### Scenario: 2本指タップで直前の操作を取り消す
- **WHEN** ユーザーがキャンバス面を2本指で素早くタップしたとき
- **THEN** 直前に描かれたストロークまたは消去操作が1ステップ取り消され（Undo）、インクの誤描画は発生しない

### Requirement: 3本指タップによるやり直し (Redo)
システムは、キャンバス面上で3本の指による素早いタップ操作を検知したとき、取り消された操作を1ステップやり直さなければならない (SHALL)。このジェスチャーによって意図しないインク描画が発生してはならない (MUST NOT)。

#### Scenario: 3本指タップで取り消した操作をやり直す
- **WHEN** ユーザーがキャンバス面を3本指で素早くタップしたとき
- **THEN** 取り消されていたストローク操作が1ステップやり直され（Redo）、インクの誤描画は発生しない

### Requirement: 2本指ピンチによるズームおよびパン操作
システムは、キャンバス面上で2本の指によるピンチ操作（指間距離の伸縮または指中心点の移動）を検知したとき、紙面の表示倍率を拡大・縮小（50%〜300%）し、指の移動に合わせてパン移動を行わなければならない (SHALL)。拡大・縮小状態においてもスタイラスペンによる手書き描画位置とベクター座標は正確に一致しなければならない (MUST NOT)。

#### Scenario: 2本指ピンチでの拡大縮小
- **WHEN** ユーザーが紙面上に2本指を置き、指の間隔を広げたり狭めたりしたとき
- **THEN** 指間距離の変化に連動して紙面が滑らかに拡大・縮小表示される

#### Scenario: ズーム表示中のペン描画追従
- **WHEN** 紙面を拡大（例えば150%や200%）した状態でApple Pencilで文字を描いたとき
- **THEN** 拡大倍率に応じた座標変換が正確に行われ、ペン先とインク描画位置がずれることなく高精細に筆記できる
