# Spec Delta

## MODIFIED Requirements

### Requirement: Apple Pencilおよびスタイラスによる低遅延ストローク描画
システムは、PointerEvent を用いて筆圧を検知し、未確定ストロークを描画中の差分（インクリメンタル）追記およびペン先予測（Predictive Inking）を用いて、遅延なく即座にレンダリングしなければならない (SHALL)。ストロークが長くなった場合でも描画計算負荷が累積してはならない (MUST NOT)。

#### Scenario: ペンによる描画追従
- **WHEN** ユーザーがスタイラスペンまたはApple Pencilで紙面をなぞったとき
- **THEN** 差分追記描画によりストローク長に関わらず遅延なくインクが表示され、ペンを離すと確定レイヤーに転写される

#### Scenario: パームリジェクション
- **WHEN** スタイラスで描画中に手のひら（touch）が画面に触れたとき
- **THEN** 手のひらによるインク描画は発生せず、ペンの描画のみが継続される

#### Scenario: ペン先到達位置の先行予測描画
- **WHEN** ユーザーがペン先を一定以上の速度で移動させているとき
- **THEN** 直前の移動速度ベクトルから次フレームの到達予測点が算出され、表示遅延を相殺してペン先に密着するように先行インクが表示される
