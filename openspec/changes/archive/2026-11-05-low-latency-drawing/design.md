# Design

## Context

See `proposal.md` for motivation.
現在の StarNote では、ペン入力時にアクティブCanvas全体をクリアし、ストローク開始からの全点列に対して `perfect-freehand` を毎フレーム実行しています。このため、描画時間が長くなるほど計算量と描画負荷が O(N) で増大し、iPad Safari 上でペン先からの遅延（モサつき）が発生しています。

## Goals / Non-Goals

**Goals:**
- 描画中の計算量をストローク長に関わらず O(1)（一定時間）に抑える差分追記レンダリングの実装
- ペン先の移動速度・方向ベクトルに基づく予測点（Extrapolated Points）の先行描画による体感レイテンシ削減
- ペン離脱（pointerup）時の `perfect-freehand` 高精度清書と確定線Canvasへのシームレスな統合
- 既存機能（スクラブ消去、図形自動整形ホールド、なげなわ選択）との完全な互換性維持

**Non-Goals:**
- WebGL / WebGPU への全面移行（Canvas 2Dコンテキストのパイプライン最適化で十分なパフォーマンスが得られるため、今回は対象外）
- 機械学習モデルを用いた重厚な軌跡予測（数式ベースのカルマン・外挿フィルタで軽量に実装）

## Decisions

### Decision 1: 2段階レンダリング（差分追記 ＋ 最終清書）
- **Rationale**: 
  - 描画中（ペン先が接地している間）は、`activeCanvas` 全体を消去せず、直前の点 $P_{n-1}$ から現在の点 $P_n$ への最新セグメント（筆圧に応じた線幅）のみを Canvas に直接追記（`stroke()`）します。
  - これにより、毎回のポインタイベントでの処理は数マイクロ秒（O(1)）で完了し、ストロークがどれだけ長くなっても遅延が一切累積しません。
  - ペンを離した瞬間にアクティブCanvasをクリアし、ストローク全点列を `perfect-freehand` で計算した滑らかな曲線ポリゴンとして確定線Canvasへ転写します。

### Decision 2: 先行予測（Predictive Inking）とダンピング
- **Rationale**:
  - 最新の入力点と直前の入力点の移動ベクトル $\vec{v} = (x_n - x_{n-1}, y_n - y_{n-1})$ を算出。
  - ディスプレイ表示遅延（1フレーム: 約8〜12ms）を相殺するため、速度に応じた外挿点 $P_{pred} = P_n + \vec{v} \times \alpha$（$\alpha \approx 0.7$）を生成して先端を先行描画。
  - **急激な方向転換への対策**: 連続する2つのベクトルの内積が負（鋭角な折り返し）または移動速度が急減速した場合は、予測長を即座に 0 へ減衰（Damping）させ、不要な線の飛び出し（オーバーシュート）を完全に防止します。

### Decision 3: ジェスチャー検出との並行協調
- **Rationale**:
  - スクラブ消去判定、図形ホールドタイマー（400ms）、輪郭ホールドタイマー（350ms）は、ストローク点配列 `activePointsRef` を内部で蓄積しつつ独立して動作。
  - 図形認識スナップが発火した時のみ、差分追記モードからスナップ図形プレビュー（青破線）へ切り替えることで、既存のインテリジェントジェスチャー機能を損なうことなく超高速描画を両立します。

## Risks / Trade-offs

- **[Risk] 差分追記の描画線と、離した瞬間の `perfect-freehand` 清書線で形状のわずかなズレ（ジャンプ）が見える** → **Mitigation**: 差分追記時にも線の太さと端点の丸み（`lineCap = 'round'`, `lineJoin = 'round'`）を `perfect-freehand` の筆圧マッピング式に忠実に合わせることで、確定時の視覚的違和感を極小化します。
- **[Risk] ペン先予測によるオーバーシュート** → **Mitigation**: 最大予測距離をペン太さの2倍程度に制限し、かつ急旋回時には予測をカットする安全閾値を設定します。
