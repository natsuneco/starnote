# Spec Delta

## MODIFIED Requirements

### Requirement: ペンおよび蛍光ペンツールの描画表現
システムは、入り抜きによる先端・終端の極端な細りや消失のない均一な丸ボールペン描画（Round Cap / Round Join）を提供する通常ペン描画と、既存の線を透過・強調する乗算合成の蛍光ペン描画を提供しなければならない (SHALL)。単一タップや短いストローク（濁点や句読点など）においても、線幅に応じた円形ドットとして確実に可視化されなければならない (SHALL)。

#### Scenario: 丸ペン（ボールペン）による均一線描画
- **WHEN** ペンツールを選択して紙面に文字や線を描いたとき
- **THEN** 筆圧や速度による過度な入り抜き（Tapering）や細り（Thinning）が発生せず、選択された太さの均質で滑らかな丸ペンストロークが描画される

#### Scenario: 単一タップおよび極小点の確実なドット描画
- **WHEN** ペンツールで紙面を1回タップしたり、濁点・半濁点・ピリオド等の極小ストロークを描いてペンを離したとき
- **THEN** ドットが縮小・消失することなく、選択太さに応じた明瞭な円形ドットとしてキャンバスに描画・確定される

#### Scenario: 蛍光ペンによる強調
- **WHEN** 蛍光ペンツールを選択して既存の黒文字の上をなぞったとき
- **THEN** 黒文字が隠れることなく下地が透け、半透明のハイライトとして重なり描画される
