# Design: 通常丸ペン（ボールペン）描画エンジン

## Context

現在のストローク生成ロジック（`src/lib/drawing/stroke.ts` および `src/lib/pdf/generator.ts`）は、カリグラフィー調の入り抜きブラシ（`thinning: 0.6`, `taper: size * 0.5`）を使用しています。このため、短いストロークや濁点・ピリオド等のタップ入力時に輪郭多角形が極小化または計算不能となり、ドットが消失する不具合が発生していました。
詳細は [proposal.md](./proposal.md) を参照してください。

## Goals / Non-Goals

**Goals:**
- ペン先および終端での入り抜き（Taper）を完全に排除し、常に選択された太さ（size）の丸い端点（Round Cap）を生成する。
- 筆圧・速度による線幅縮退（Thinning）をゼロ（または実質均一）とし、均質で予測しやすいボールペン描画を実現する。
- 1点のみの単一タップや極小移動ストロークにおいて、`Path2D.arc` による確実な正円ドット（半径 `size / 2`）を生成・レンダリングする。
- PDF エクスポート（ベクター変換）においても同一のパラメータとドット描画を同期する。

**Non-Goals:**
- ペン種類の動的切り替えUI（「万年筆」「ボールペン」「筆ペン」のセレクター追加）は今回スコープ外とし、既存のペンツール（`pen`）をボールペン仕様へ更新する。

## Decisions

### 1. 従来の入り抜き・多角形生成（`perfect-freehand`）の全廃とネイティブ丸ペン化
- **決定**: ペン描画における `perfect-freehand` によるポリゴン輪郭計算・塗りつぶし処理を完全に削除し、Canvas 2D ネイティブの丸ペン描画（`lineWidth = size`, `lineCap = 'round'`, `lineJoin = 'round'` による `ctx.stroke()`、および単一点の `ctx.arc()`）へ置き換える。
- **理由**:
  - `perfect-freehand` は筆圧や入り抜きのある毛筆・万年筆風のポリゴンを算出するためのライブラリであり、通常の丸ボールペンを描画するには余計な計算オーバーヘッドと「点の消失」「端点ポリゴンの縮退」という構造的欠点があった。
  - ネイティブの 2D パス（中間点スプライン補間 + ラウンドキャップ/ジョイン）を用いることで、GPUアクセラレーションが最大限に活かされ、極めて軽量かつ確実に一定太さの丸いストロークが得られる。
  - 描画中の差分追記（`renderIncrementalSegment`）と確定後の全描画（`renderStroke`）の描画ロジックが完全に同一となり、ペンを離した瞬間に太さや形が変わる違和感が完全にゼロになる。

### 2. 単一タップ・極小ストロークの独立円形パス生成
- **決定**: ストロークのポイント数が1点のみ、または総移動距離がごくわずかな場合、中心点 `(x, y)` に半径 `size / 2` の円（`ctx.arc`）を直接描画する。
- **理由**: 濁点・半濁点・ピリオド・小文字のアクセントなど、微小なタップ操作で生成されるドットが 100% 確実に選択サイズ通りの綺麗な円として残ることを幾何学的に保証する。

### 3. PDF ベクターエクスポートのネイティブ線化
- **決定**: PDF 生成においても `perfect-freehand` の多角形（Polygon Z）出力処理を廃止し、SVG パスの直線/スプライン＋`stroke-linecap="round"` / `stroke-linejoin="round"` によるネイティブなベクター線として出力する。
- **効果**: PDF ファイルサイズが大幅に削減（約 1/5 以下）され、拡大時もボケやジャギーのない極めてシャープな丸ペンベクター線となる。

## Risks / Trade-offs

- [筆圧による強弱表現の消失] → ボールペンとしての均一性を優先。線の太さはツールバーの太さピル（1/2/4/8px等）で明確に選択可能であるため、文字の安定した筆記性が向上する。
- [描画負荷の変化] → `taper: 0` の方が多角形頂点数が少なく単純化されるため、むしろ描画パフォーマンスは向上する。
