# Proposal: 通常丸ペン（ボールペン）描画への刷新

## Why

現在の手書きペン描画は `perfect-freehand` の筆圧・速度による強い入り抜き（`thinning: 0.6`, `taper: size * 0.5`）が適用されているため、短いタッチや句読点・濁点・ピリオド等の細かな点が極小化または消失してしまい、文字の筆記性が著しく損なわれています。
GoodNotes のボールペンのような、先端と終端が丸く（Round Cap/Join）、均一かつ直感的な太さで確実に入力できる「普通の丸ペン（ボールペン）」描画スタイルに刷新することで、細かい文字や記号をストレスなく快適に筆記できるようにします。

## What Changes

- **従来の入り抜きペン処理（`perfect-freehand` 多角形生成）の削除**: ペン離脱時にポリゴン輪郭を計算して塗りつぶしていた従来の処理を全廃し、ネイティブな標準丸ペン（Round Cap / Round Join のストローク描画）に置き換えます。
- **ペンの入り抜き（Taper）および細り（Thinning）の完全排除**: 筆圧や速度による先端・終端の縮退をなくし、指定された太さ（size）の均一な丸い線を常に描画します。
- **単一タップ・極小ストロークの正円ドット描画保証**: 濁点やピリオド、極小フリックなどの短いストロークが縮小・消失せず、指定太さの円形ドット（半径 `size / 2`）として確実に描画・確定されるようにします。
- **描画中と確定線の完全一致**: 差分追記描画中（リアルタイム）とペン離脱後（確定後）でまったく同じ線幅・端点形状・パス表現を使用し、線の変化やブレをゼロにします。
- **PDF エクスポートの同期と軽量化**: エクスポートされる PDF においても多角形塗りつぶしではなく、ネイティブな丸ペン線ストローク（Line Cap / Line Join）で出力し、描画精度とファイル容量の軽量化を両立します。

### Modified Capabilities
- `drawing-engine`: ペンツールの描画表現について、入り抜き付きブラシから均一な丸ボールペン描画へと仕様を更新し、極小ドットの描画保証を明記します。

## Impact

- 影響を受けるコンポーネント・モジュール:
  - `src/lib/drawing/stroke.ts`: `getStrokePath2D`, `renderDot`, `renderIncrementalSegment` のパラメータ調整
  - `src/components/editor/DrawingCanvas.tsx`: 単一タップや極小点ストローク確定時の座標補正処理
  - `src/lib/pdf/generator.ts`: PDF ベクターパス生成時の `getStroke` パラメータ同期
- 外部APIやデータスキーマ（`Stroke` 型）への破壊的変更はありません。
