# Design: 親scale撤廃と用紙実寸スケーリングによる真の高精細ベクターズーム

## 1. 概要
親要素の CSS `transform: scale()` による GPU レイヤー強制ダウンサンプリングと低解像度ビットマップ引き伸ばし（バイリニアボケ）を完全に撤廃し、用紙自体の CSS 実寸幅を拡大する「真のベクターズームアーキテクチャ」を採用します。

## 2. 根本原因と解決
- **原因**: 親コンテナに `scale()` が指定されていると、WebKit / Chromium は親のローカルレイヤーサイズ（等倍解像度）で一度ダウンサンプリングしてから GPU で引き伸ばすため、子 Canvas の解像度をいくら上げても粗いままになっていた。
- **解決策**:
  1. 親の `transform` から `scale()` を全廃し、`translate3d` によるパン移動のみにする。
  2. 用紙コンテナの幅を `BASE_PAGE_WIDTH (840px) * zoomScale` の実寸 CSS ピクセルで拡大配置。
  3. Canvas は拡大された用紙の実寸サイズを受け取り、物理ピクセル（`dpr`、最大 4096px 安全ガード付き）で直接レンダリング。
  4. ストロークデータは基準座標系（`0 〜 840`）のまま保持し、Canvas コンテキストのマトリックス変換（`ctx.setTransform`）で用紙サイズに合わせて直接ラスタライズ。
  5. テンプレート SVG も実寸でネイティブラスタライズされるため、用紙のすべての要素が物理ピクセルと 1:1 に一致した極上のシャープさを実現。
