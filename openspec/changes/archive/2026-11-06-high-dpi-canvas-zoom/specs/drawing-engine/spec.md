# Spec Delta

## ADDED Requirements

### Requirement: ズーム表示倍率に連動した用紙実寸スケーリングと高精細ベクター描画 (High-DPI Vector Zoom)
システムは、用紙のズーム操作時において親要素のCSS変形による低解像度ビットマップ引き伸ばし（バイリニアボケ）を排除するため、用紙コンテナのCSS幅・高さを拡大倍率に応じて実寸スケーリングし、キャンバスおよびベクターストロークを画面の物理解像度に合わせてダイレクトに高精細レンダリングしなければならない (SHALL)。また、ストロークデータは基準座標系（Normalized Base Coordinates）で統一管理し、拡大・等倍・PDF出力間での座標および描画太さの完全な互換性を維持しなければならない (SHALL)。過度な拡大によるメモリ消費やクラッシュを防止するため、キャンバスの物理解像度には適切な上限（長辺4096px安全ガード）を設けなければならない (SHALL)。

#### Scenario: 拡大表示時のクッキリとした高精細レンダリング
- **WHEN** ユーザーが用紙を等倍（100%）より大きく拡大（例: 200%〜400%）したとき
- **THEN** 用紙の実寸拡大に合わせてキャンバスの解像度が物理ピクセルに合わせてスケールアップされ、手書き線・図形・テンプレート罫線がぼやけることなくRetinaディスプレイ極限の鮮明さでレンダリングされる

#### Scenario: ピンチ中心点（Focal Point）の正確な追従
- **WHEN** ユーザーが2本指ピンチ操作によって画面上の任意の位置を中心として拡大縮小を行ったとき
- **THEN** 水平中央揃えレイアウトを補正した中心基準の幾何学計算により、ピンチしている指先直下のコンテンツ位置が不変に維持されたまま自然にズームする

#### Scenario: なげなわ選択UIの正確なスケーリング追従
- **WHEN** 用紙が拡大表示されている状態でなげなわ選択ツールや輪郭ホールドによってオブジェクトを選択したとき
- **THEN** 青い破線の選択バウンディングボックスおよびアクションメニュー（削除・解除）が、拡大されたオブジェクトの真上に寸分の狂いなくピッタリ追従して表示される

#### Scenario: メモリ安全上限の遵守
- **WHEN** 用紙を大幅に拡大（最大400%など）した場合
- **THEN** キャンバスの物理解像度はテクスチャ安全上限（4096px）を超えず、iPad Safari のメモリクラッシュを確実に防止しながら安定して描画が維持される
