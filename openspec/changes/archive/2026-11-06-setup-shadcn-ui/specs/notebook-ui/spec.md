# Spec Delta

## MODIFIED Requirements

### Requirement: ホーム画面でのノート一覧表示と作成
システムは、作成済みノートをグリッド形式で一覧表示し、共通UIコンポーネント（Dialog/Input/Button等）に基づいた新規ノート作成ダイアログを提供しなければならない (SHALL)。

#### Scenario: ノートの新規作成
- **WHEN** ユーザーが新規作成ボタンをクリックし、タイトルを入力して確定したとき
- **THEN** 新しいノートが作成されて一覧に追加され、編集画面へ自動遷移する

#### Scenario: ノートの削除
- **WHEN** ユーザーがノートカードの削除操作を行ったとき
- **THEN** 対象のノートが一覧から削除される

### Requirement: 編集画面ツールバーによる描画ツールの選択
システムは、編集画面の上部にすりガラス質感を持つ共通UIツールバーを配置し、ペン種別（ペン、マーカー、消しゴム、なげなわ）およびポップオーバー等によるカラー・太さセレクターの選択状態を管理・表示しなければならない (SHALL)。

#### Scenario: 描画ツールの切り替え
- **WHEN** ユーザーがツールバー上のペンまたはマーカー等のツールアイコンをクリックしたとき
- **THEN** 選択されたツールのアクティブ状態がハイライト表示される

#### Scenario: ペン詳細設定ポップオーバーの操作
- **WHEN** ユーザーがカラーや太さの詳細設定アイコンをクリックしたとき
- **THEN** スムーズなポップオーバーが表示され、色やストローク太さを直感的に選択・調整できる
