# Spec Delta

## Purpose

Radix UI と Tailwind CSS v4 を基盤とした、アクセシブルで iPadOS ライクな質感（すりガラス・タッチフィードバック）を持つ共通 UI コンポーネント群を提供し、アプリケーション全体の視覚的・操作的統一性を担保します。

## ADDED Requirements

### Requirement: 共通UIコンポーネント基盤の提供
システムは、ボタン、ダイアログ、ポップオーバー、スライダー、シート（ハーフモーダル）、ツールチップなどの汎用的な共通 UI コンポーネント群を提供しなければならない (SHALL)。

#### Scenario: ボタンコンポーネントの操作
- **WHEN** ユーザーがボタンをタップまたはクリックしたとき
- **THEN** タッチフィードバック（スケール変化）が提示され、指定されたアクションが実行される

#### Scenario: ダイアログ・シートの表示と閉じる操作
- **WHEN** ユーザーがダイアログまたはシートを開くトリガーを操作したとき
- **THEN** スムーズなアニメーションとともにコンテンツが表示され、背景タップや閉じる操作で自然に閉じられる

### Requirement: iPadOSライクな視覚スタイルとアクセシビリティの統合
システムは、Tailwind CSS v4 のデザイントークンを活用し、すりガラス効果（backdrop-blur）や角丸、ハイコントラスト対応、スクリーンリーダー配慮などのアクセシビリティ標準を満たさなければならない (SHALL)。

#### Scenario: すりガラス質感の反映
- **WHEN** ツールバーやポップオーバーなどの浮遊 UI 要素が表示されたとき
- **THEN** 背景が半透明およびぼかし処理され、背後の紙面やキャンバスがうっすらと透過して視認できる

#### Scenario: キーボードおよび支援技術からの操作
- **WHEN** キーボードや支援技術を用いて UI コンポーネントにフォーカスしたとき
- **THEN** 適切なフォーカスリングが表示され、標準的なキーボードショートカット（Escapeで閉じる等）が機能する

### Requirement: 手書き描画キャンバスとのポインター競合防止
システムは、UI コンポーネントの操作時にスタイラスペンや指による手書きストローク描画が誤って発火しないよう、イベント伝播を適切に分離・制御しなければならない (SHALL)。

#### Scenario: UIコンポーネント操作中の描画抑止
- **WHEN** ユーザーがツールバー上のボタンやスライダーをスタイラスまたは指で操作したとき
- **THEN** UI 操作のみが反応し、背後の手書きキャンバスに不要な点や線が描画されない
