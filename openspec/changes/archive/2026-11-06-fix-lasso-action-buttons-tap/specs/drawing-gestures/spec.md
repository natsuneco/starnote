# Spec Delta

## MODIFIED Requirements

### Requirement: 閉ループストロークの輪郭ホールドによるなげなわ選択
システムは、始点と終点が近接する閉じたループストロークを描いて一度ペンを離した後、その輪郭線上をペン先で長押しホールド（手ブレを除き約750ms静止）したとき、またはなげなわ選択ツールで囲んだとき、当該ループをなげなわ選択枠へ変換し、内部のストロークを選択状態にしなければならない (SHALL)。選択状態中は対象オブジェクトを囲むバウンディングボックスおよびアクションメニュー（削除・解除）を表示し、スタイラスペンまたはタッチによるボタンタップ操作をキャンバス描画と競合させることなく確実に受け付けなければならない (SHALL)。

#### Scenario: 輪郭ホールドによる選択発火
- **WHEN** 閉ループストロークを描いた直後に、その輪郭線上をペン先で約750ms静止ホールドしたとき
- **THEN** ループ線が選択用の点滅・破線枠へ変化し、ループ内部に囲まれたすべてのストロークが選択状態になる

#### Scenario: 選択されたストロークの移動
- **WHEN** ユーザーが選択状態のオブジェクト（ストローク本体または選択領域内部）をドラッグしたとき
- **THEN** 選択されたストローク全体がドラッグ操作に追従して滑らかに移動する

#### Scenario: ペンタップによる選択ストロークの削除
- **WHEN** ストロークが選択されている状態で、アクションバーの「削除」ボタンをApple Pencilまたは指先でタップしたとき
- **THEN** キャンバス上に不要なインクを描画することなく、選択されていたストローク群が一括削除され、選択状態が終了する

#### Scenario: ペンタップによる選択解除
- **WHEN** ストロークが選択されている状態で、アクションバーの「✕」ボタンをApple Pencilまたは指先でタップしたとき
- **THEN** キャンバス上に不要なインクを描画することなく、ストロークはそのまま残存した状態で選択状態のみが解除される
