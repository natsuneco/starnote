# notebook-ui Specification

## Purpose
ノート一覧（ホーム画面）、ノート新規作成、およびノート編集画面のUIナビゲーションとツールバー・紙面レイアウトを提供し、快適な手書きノートの閲覧・編集動線を実現します。

## Requirements

### Requirement: ホーム画面でのノート一覧表示と作成
システムは、作成済みノートをグリッド形式で一覧表示し、共通UIコンポーネント（Dialog/Input/Button等）に基づいた新規ノート作成ダイアログを提供しなければならない (SHALL)。

#### Scenario: ノートの新規作成
- **WHEN** ユーザーが新規作成ボタンをクリックし、タイトルを入力して確定したとき
- **THEN** 新しいノートが作成されて一覧に追加され、編集画面へ自動遷移する

#### Scenario: ノートの削除
- **WHEN** ユーザーがノートカードの削除操作を行ったとき
- **THEN** 対象のノートが一覧から削除される

### Requirement: ノート編集画面とホーム画面の遷移
システムは、一覧画面で選択したノートを編集画面で開き、戻る操作によって一覧画面へ復帰できなければならない (SHALL)。

#### Scenario: 既存ノートを開く
- **WHEN** ユーザーが一覧から任意のノートカードをクリックしたとき
- **THEN** 該当ノートの編集画面が表示される

#### Scenario: ホーム画面へ戻る
- **WHEN** 編集画面の上部ツールバーにある「戻る」ボタンをクリックしたとき
- **THEN** ホーム（一覧）画面に戻る

### Requirement: 編集画面ツールバーによる描画ツールの選択
システムは、編集画面の上部にすりガラス質感を持つ共通UIツールバーを配置し、ペン種別（ペン、マーカー、消しゴム、なげなわ）およびポップオーバー等によるカラー・太さセレクターの選択状態を管理・表示しなければならない (SHALL)。

#### Scenario: 描画ツールの切り替え
- **WHEN** ユーザーがツールバー上のペンまたはマーカー等のツールアイコンをクリックしたとき
- **THEN** 選択されたツールのアクティブ状態がハイライト表示される

#### Scenario: ペン詳細設定ポップオーバーの操作
- **WHEN** ユーザーがカラーや太さの詳細設定アイコンをクリックしたとき
- **THEN** スムーズなポップオーバーが表示され、色やストローク太さを直感的に選択・調整できる

### Requirement: 編集画面における縦スクロール紙面レイアウト
システムは、編集画面のメイン領域において、GoodNotesのようにノート用紙が中央に配置され、縦方向にスクロールして紙面を閲覧できるビューポートレイアウトを提供しなければならない (SHALL)。

#### Scenario: 縦スクロールによる紙面操作
- **WHEN** ユーザーが編集画面のメイン領域をスクロールしたとき
- **THEN** 上部ツールバーは画面上部に固定されたまま、中央のノート用紙領域が縦方向に滑らかにスクロールする
